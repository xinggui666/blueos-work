# 管理后台（规格第十七章）

入口 `/admin`。导航里的“后台”只对有后台角色的账号显示，但**这只是体验**：每个后台接口（`admin*`）都在服务端检查角色权限，普通用户直接调接口一律 403（`scripts/e2e/admin-api.mjs` 逐个验证了 31 个接口）。所有写操作写审计记录。

## 角色

| 权限 | 审核员 | 运营 | 管理员 | 超级管理员 |
| --- | --- | --- | --- | --- |
| 查看用户、补发积分、开通会员、授权组件 | | ✔ | ✔ | ✔ |
| 封禁、改角色、开发者资格 | | | ✔ | ✔ |
| 组件编辑/版本/资源、套餐、系统开关、APP 版本、审计 | | | ✔ | ✔ |
| 投稿审核 | ✔ | | ✔ | ✔ |
| 卡密、订单、构建查看与取消/重试、公告 | | ✔ | ✔ | ✔ |

空库时第一个调用接口的账号成为超级管理员；生产环境用 `BOOTSTRAP_ADMIN_EMAIL` 限定这个邮箱。只有超级管理员能封禁管理员、授予或撤销超级管理员；至少保留一个超级管理员。

## 各模块

- **总览**：用户数、7/30 天活跃（按客户端访问记录）、工程数、上架组件、有效会员、30 天积分消耗（按“确认扣分”流水）、订单统计和金额、构建成功率（成功 ÷（成功 + 失败），不可用和取消不计入）、失败原因排行、存储（工程、修订、构建产物、组件资源、数据库总量）。
- **用户**：搜索；资料、角色、会员、各类积分余额和预扣、设备；封禁（立即吊销所有登录会话）/解封；角色；积分补发/扣回（写流水）；开通/续期会员；组件授权和撤销；工程列表和**只读查看**（查看本身写审计 `project.view`）；构建和任务；积分流水；操作记录。
- **组件**：名称、分类、简介、详细说明、授权方式、上下架、SDK 兼容范围、依赖（必须是已存在的组件，不能依赖自己）；发布新版本（版本号必须递增）、停用旧版本（当前最新版本不能停用）；上传资源（只收 PNG/JPEG/WebP，按文件头判断，SVG 拒绝，单个 ≤ 256 KB，每个组件 ≤ 20 个）。
- **投稿**：机器检查结果、审核意见、通过并上架 / 退回 / 拒绝。机器检查没通过不能上架。
- **套餐**：名称、价格、有效天数、RPK 打包/下载/源工程积分（含每月、赠送）、工程上限、存储空间、并发构建数、构建优先级、**组件权限**（会员可用的组件分类，留空为全部会员组件）、生效状态。开通时保存快照，改套餐不影响已开通的会员。
- **卡密**：批量生成（类型、有效期、数量、内容）；明文只在生成后显示一次，数据库只存哈希；批次统计（未用/已用/作废/过期）；按批次和状态筛选；冻结、作废；**导出安全清单**（CSV，只含掩码提示，不含明文，单元格防公式注入）；兑换记录（成功和失败尝试）。卡密兑换可以用开关关闭。
- **订单**：列表和状态筛选；详情（用户、套餐快照、备注）；确认到账（两个管理员同时确认也只发放一次）、取消；退款/撤销（只结束这笔订单开通的会员段，按实际发放的流水扣回，余额不足时记录差额）；权益发放记录和操作记录。
- **构建**：队列统计；Worker 列表（工具链即 SDK 版本、沙箱、是否能出正式签名包、心跳）；失败原因；按状态和关键字筛选；任务详情（日志、产物检查、环境、积分结算流水、重试链）；取消；**重试**；下载产物。
  - 重试只对失败或已取消的任务开放，用同一份源工程新建任务，积分状态 `waived`（不预扣、不扣分）。原任务的预扣早已退回，所以管理员重试不会让用户被重复扣分；两个管理员同时点重试只会建一个任务（数据库唯一索引）。
- **APP 版本**：版本名、版本号、更新说明、APK 地址（只收 https，必须同时填 SHA-256）、大小、最低支持版本、强制/普通更新、测试版/正式版、**灰度比例**（按用户和版本哈希分桶，同一用户结果稳定）、**发布时间**（未到时间不推送）、启用。没有真实安装包时客户端显示“不可下载”（`downloadable: false`）。
- **开关**：开放注册、组件商城、会员购买、卡密兑换、组件投稿、投稿自动上架、源工程生成、工程下载、RPK 构建、显示公告、**维护模式**（普通用户只读，管理员不受影响）。
  - 开关只影响服务器上的操作。生成的 RPK 在手表上独立运行，不读取远程配置，服务器或远程配置不可用不会让它失效。
- **公告**、**审计**。

## 测试

- `scripts/e2e/admin-api.mjs`（13 步）：普通用户 31 个后台接口全部 403；审核员越权被拒；总览统计；用户详情和只读查看审计；组件编辑、依赖校验、版本、资源（SVG 和超大文件被拒）；套餐组件分类权限生效；卡密批次、无明文清单、兑换记录、关闭兑换；订单详情、确认、退款；APP 版本灰度和定时发布；维护模式和下载/公告开关；构建超时失败退回 → 并发重试只建一个 → 成功且不扣分 → 后台下载产物哈希一致。
- `scripts/e2e/web-admin.mjs`（4 步）：网页逐个打开 12 个标签页无错误；用户详情里补发积分、授权组件；切换开关；普通用户打开 `/admin` 只看到“没有权限”。
- 单测 `src/lib/platform/admin-rules.test.ts`：图片类型判断、清单防注入、灰度分桶、套餐组件分类规则。
