# 网页工坊逻辑编辑器（阶段 3）

编辑器右侧分 5 个区：组件、图层、属性、逻辑、交付。顶部可以切换编辑、预览、调试，以及简易/高级模式。

## 1. 工程在浏览器里怎么存

- 打开工程时，旧格式的工程（v1 编辑器格式、旧 DSL）会**一次性**转成协议 v2，结果存进 `protocolExtras`，并加上 `native: true`。
- 转换后，编辑器的工程对象只保存画面：页面、组件、导航和元信息。
- 变量、事件、函数、计时器和绑定都只存在 `protocolExtras` 里，ID 固定，来回转换不丢内容（`src/lib/protocol/editor.ts`：`toNative`、`projectToDoc`、`docToProject`）。
- 删除组件或页面时，指向它的事件、绑定和页面变量会在 `projectToDoc` 里一起去掉，不会在下次同步时又出现。
- 撤销/重做的快照包含 `protocolExtras`，所以逻辑修改也能撤销（`model.ts` 中的 `snapshotOf` 和 `restoreSnapshot`）。
- 阶段 4 之前，打包生成仍走旧生成器，由 `legacyForGenerator` 宽松降级提供数据。v1 表达不了的内容（如 `count + 1` 这类表达式赋值）生成时会被丢弃，阶段 4 改为直接消费协议。

## 2. 页面与组件

- 页面：新增、删除、复制、改标题、前后移动。复制页面时，组件、绑定和组件事件一起复制，ID 全部重新生成。
- 组件：复制（Ctrl+D）、对齐（左/中/右/上/中/下）、等距分布（横/竖），撤销重做。
- 图层面板显示层序号。
- 属性面板：恢复默认外观、数据绑定、点击动作、其他事件。

## 3. 事件

- 触发器分 5 类：组件、页面、时间、变量、系统。简易模式只显示前 3 类。
- 每个事件可以设置条件表达式、节流、启用/停用、上移下移、复制和删除。
- 动作可以嵌套：条件、循环、调用函数等放在高级模式里。每个动作都可以移动、复制和删除。
- 真机还没验证过的触发方式会标出来。预览可以模拟这些触发，但不承诺手表支持。

## 4. 变量

- 类型、作用域（全局/页面）、是否持久化、说明都可以设置。
- 改名时，所有表达式里的引用一起改（`renameVariable`）。函数里有同名参数或局部变量遮住它的地方不改。
- 改类型前会先算出会新增哪些错误，确认后才改。
- 每个变量下面列出引用它的地方，点一下就跳到那里。

## 5. 绑定

- 数据来源有 3 种：变量、表达式（高级模式）、时间。
- 时间绑定可选时间字段、格式和刷新频率，也可以关联计时器。
- 表达式在输入时实时检查语法和结果类型。

## 6. 函数（高级模式）

- 可以设置参数、局部变量、返回类型和函数体。
- 显示调用方和被调用函数，修改时版本号加一。
- 超出协议上限（`PROTOCOL_LIMITS`）时不让再加。

## 7. 检查

- 「检查」页列出 `validateDoc` 的全部错误和警告。
- 点一条就跳到对应的事件、动作、变量、绑定或组件（`issueTarget`、`locateRef`）。

## 8. 预览与调试

- 预览直接跑协议解释器（`runtime.ts`）。支持点击、双击、长按、四个方向滑动、按下和松开。
- 调试面板：
  - 时间：暂停、快进（+1 分钟、+1 小时、+1 天）、恢复真实时间。
  - 模拟切到后台和回到前台，重启应用。
  - 查看和修改变量值，查看计时器状态。
  - 事件列表，可以手动「触发」，停用的事件会给出警告。
  - 执行记录带耗时，可以筛选、清空，点一条跳到对应节点。循环超限和错误会标出来。

## 9. 交付

- 显示协议摘要和校验错误（点错误可以跳过去）。
- 可以下载 `.bproj`。
- 可以校验本地 `.bproj`：检查完整性（每个文件的 SHA-256 和内容 SHA-256），并列出迁移步骤。

## 10. 测试

- `npm test`：`src/lib/protocol/stage3.test.ts` 覆盖转换往返、改名、引用、定位、作用域、调用图和解释器接口。
- 端到端测试（需要一个正在运行的服务）：`E2E_BASE=http://localhost:8080 npm run e2e:logic`。
  - 流程：注册，新建工程，加按钮、变量和点击事件（`count + 1`），加表达式绑定和时间绑定。
  - 然后：检查页无错误，预览中点两次显示「次数 2」，调试器改变量，时间快进。
  - 最后：确认云端协议文档能通过服务端校验，再测撤销和重做。

## 11. 已知限制

- 新加的组件默认放在画面中间，几个组件会叠在一起，需要手动挪开。
- 时间触发和系统事件只在预览里模拟，没有在真机验证。
- 打包仍是旧生成器，见第 1 节。
