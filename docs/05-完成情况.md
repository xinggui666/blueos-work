# 已完成和未完成

已完成，并且可以在网站里操作：

- 注册登录后才能编辑。游客不能进编辑器。
- 编辑、预览、保存不扣额度。
- 新注册账号没有打包、生成、下载额度。已经发过的旧额度不追回。
- 没有会员时最多 3 个工程。套餐可以改工程上限，0 表示不限制。
- 会员套餐由后台新建，名称、价格、天数、额度不写死。
- 打包次数、会员、组件卡密分开。买次数不会解锁会员组件。
- 额度预扣、成功确认、失败释放。官方构建失败或未执行时不扣打包次数。
- 组件编号 MB001 起。
- 客户端版本记录、更新说明、https 安装包地址和 SHA-256。没有真实安装包时不填地址。
- 多页面编辑、动作预览、源工程 ZIP。
- 网页、Android、桌面共用同一套登录和工程接口。

未完成，不能当成已经交付：

- 可安装的 Android APK。这台环境只有 Java，没有 Android SDK，不会放一个假的安装包。
- 桌面安装包。
- BlueOS 官方工具链编译。生成物只是源工程。
- 打包额度按日、按月自动刷新。开通会员时发放一次，之后要后台再发或等支付续期。
- 自动支付。后台可以确认订单。
- 条件判断、网络请求、组件分组旋转。
