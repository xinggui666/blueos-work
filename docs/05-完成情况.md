# 已完成和未完成

已完成，并且可以在网站里操作：

- 注册登录后才能编辑。游客不能进编辑器。
- 编辑、预览、保存不扣额度。
- 新注册账号没有打包、生成、下载额度。已经发过的旧额度不追回。
- 没有会员时最多 3 个工程。套餐可以改工程上限，0 表示不限制。
- 会员套餐由后台新建，名称、价格、天数、额度不写死。
- 打包次数、会员、组件卡密分开。买次数不会解锁会员组件。
- 额度预扣、成功确认、失败释放。官方构建失败或未执行时不扣打包次数。
- 组件编号 MB001 起。
- 客户端版本记录、更新说明、https 安装包地址和 SHA-256。没有真实安装包时不填地址。
- 多页面编辑、动作预览、源工程 ZIP。
- 网页、Android、桌面共用同一套登录和工程接口。
- 服务器端 RPK 构建（阶段 4）：v2 原生生成器把逻辑解释器一起放进 RPK，“计数 +1”这类逻辑不再丢失；独立 Worker 用蓝河官方工具链在 bwrap 隔离环境里编出签名 RPK，产物检查通过才算成功；网页交付面板可以发起构建、看状态和日志、取消、下载。详见 `docs/12-构建引擎.md`。
- 管理后台（第十七章）：总览统计、用户详情与只读查看、组件说明/版本/资源/依赖/SDK、套餐组件权限、卡密批次与安全清单、订单详情与发放记录、构建管理（重试不重复扣分）、APP 版本灰度与定时发布、维护模式等开关。详见 `docs/13-管理后台.md`。
- 新加入的组件自动找空位，不再叠在一起（圆表只放在可见圆内）。

未完成，不能当成已经交付：

- 完整的 Android 客户端（阶段 5 进行中）。
- 桌面安装包。
- 生成的 RPK 还没有在真机手表上安装运行验证（手势、生命周期、持久化都未在真机确认）。
- Docker 版构建 Worker 镜像尚未实际构建（开发机没有 Docker）。
- 打包额度按日、按月自动刷新。开通会员时发放一次，之后要后台再发或等支付续期。
- 自动支付。后台可以确认订单。
- 条件判断、网络请求、组件分组旋转。
