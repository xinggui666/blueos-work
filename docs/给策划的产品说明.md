# BlueOS 工坊 · 产品说明

给策划、运营和评审用。写的是现在这个网站里已经能操作的功能，以及明确还不能对外承诺的部分。

当前成品是这个网站和它后面的服务器。没有 Android 安装包，也没有桌面安装包。网页、以后的手机客户端和桌面客户端走同一套账号、工程和额度。

---

## 1. 产品是什么

BlueOS 工坊用来做蓝河手表上的多页面界面。

用户登录后可以免费画页面、预览、保存。把工程导成源码，或者申请官方打包，才需要额度。

导出的文件叫**源工程**。它是一套页面源码（页面、样式、清单和说明），不是可以装进手表的安装包，也不是手机 APK。

官方编译器没有接上。用户点「官方打包」之后，任务会记成「未执行」，不会扣打包次数，也不能把这个任务说成已经编译成功。

## 2. 谁在用

| 角色 | 能做什么 |
|---|---|
| 游客 | 只能停留在登录页，不能进编辑器 |
| 注册用户 | 建工程、编辑、预览、保存、看商城、兑换、下单、看任务 |
| 会员 | 在普通用户之上，按套餐获得天数、额度、工程上限和会员组件 |
| 开发者 | 申请通过后可以投稿组件，等管理员审核 |
| 管理员 | 第一个注册的人是超级管理员。后台地址是当前网站的 `/admin` |

手机上底部四个入口：工程、商城、权益、任务。  
电脑上顶部还有投稿；管理员另外能进后台。

## 3. 商业规则

这是对外口径，不要和「编辑也要付费」混在一起。

**不收费的**

- 注册、登录
- 新建和编辑页面
- 预览
- 保存到云端

**要额度的**

| 额度 | 什么时候扣 |
|---|---|
| 生成额度 | 源工程导出成功才扣 |
| 导出额度 | 这份 ZIP 第一次下载才扣，下过一次再下不扣 |
| 打包额度 | 只有官方编译真正成功才扣。现在不会扣 |

三种额度分开记，不能互相顶替。服务器先预扣，成功再确认，失败就退回。用户自己改不了余额。

**怎么获得额度**

三条路可以同时存在：

1. **购买次数**。只增加额度，不会自动变成会员，也不会解锁会员组件。
2. **卡密**。可以兑换会员、额度，或某一个指定组件。
3. **会员**。按后台配置的套餐发放天数、额度、工程数量上限和组件权限。到期之后不再发新的权益。已经生成好的源工程还在，不会被删。

新注册账号没有生成、下载、打包额度。以前已经发过的旧额度不追回。

**工程数量**

- 没有会员时，最多保存 3 个工程。
- 套餐里可以改这个上限。填 0 表示不限制。
- 复制工程也算一个新工程，同样受上限约束。

**支付**

用户可以提交订单，但这里没有自动扣款。管理员在后台确认之后，套餐里的权益才会到账。取消订单不会发权益。

**不会自动刷新的额度**

开通会员时发放一次。没有按日、按月自动补次数。要再给，就由管理员补发，或者等下一笔订单确认。

## 4. 用户怎么走一遍

1. 注册并登录。
2. 在「工程」里选模板，填写工程名、应用名、包名，选择圆表或方表。
3. 进入编辑器，加页面、摆组件、写点击动作。
4. 打开预览，看跳转、返回、提示、显示隐藏和变量是否按预期走。
5. 保存。保存不扣额度。
6. 需要源码时，导出源工程。成功后扣一次生成额度。
7. 到「任务」里下载 ZIP。第一次下载扣一次导出额度。
8. 如果要会员组件或更多额度，走购买、卡密或开通会员。

## 5. 工程

- 可以按工程名、应用名、包名搜索。
- 可以新建、复制、删除。删除要再点一次才生效。
- 模板有四个：空白应用、底部导航、设置中心、数据展示。
- 数据展示模板里有数字组件。数字和时间属于会员组件，没权限时可以编辑，但生成时服务器会拒绝。
- 表盘外形：圆表或方表。
- 设计宽度固定 466。生成坐标按这个宽度，不会因为预览窗口变大变小就改坐标。
- 包名必须像 `com.example.app`，全部小写。
- 应用名建议不超过 6 个汉字，这是商店名称的建议，不是强制截断。
- 一个工程最多 12 页。
- 页面名用来当源码目录名，必须以英文字母开头。
- 登录后的工程会写到云端。这台浏览器里也留着本地副本。

## 6. 编辑器

编辑器是给表盘界面用的，不是给手机 App 画大屏。

**画布**

- 从组件库点一下，组件就加到当前页。
- 拖动改位置，拖边缘改大小。
- 锁定之后不能再拖。
- 隐藏之后画布上看不见，源码里写成不显示。
- 图层列表里可以选中组件。
- 可以撤销、重做。
- 可以改工程名、应用名、包名、启动页、当前页背景。

**页面和导航**

- 上方页面条切换页面，也可以加页面。
- 导航可选：无、底部、顶部、侧边。
- 导航最多 4 项。

**组件**

只有下面这些。策划不要在方案里写未列出的控件，生成器不会编一个不存在的标签。

| 组件 | 策划需要知道的限制 |
|---|---|
| 文本 | 可写字、颜色、字号、对齐、字重、行数 |
| 按钮 | 可写文案、文字色、底色、字号、圆角 |
| 图片 | 可填地址、缩放方式、替代文字。不支持点击，生成时不会写点击事件 |
| 纵向、横向 | 用来分组摆放，可改底色和圆角 |
| 间距 | 占位 |
| 分隔线 | 可改颜色 |
| 矩形 | 可改底色、描边、圆角 |
| 圆形 | 可改底色 |
| 进度 | 0 到 100，可改颜色和底色，类型分横向、弧形 |
| 开关 | 可改开合、滑块色、轨道色 |
| 数字 | 会员组件 |
| 时间 | 会员组件 |
| 点击区 | 透明热区，用来接点击，本身没有可见样式 |

每个组件还可以打开「点击日志」。这只表示这个组件响应点击，真正做什么由下面的动作决定。

**一个组件上的点击动作**

最多 8 个，按从上到下的顺序执行。

- 打开某一页
- 返回上一页
- 弹出一句提示
- 显示某个组件
- 隐藏某个组件
- 修改某个组件的文字
- 修改某个变量的值

没有这些能力，方案里不要写：

- 长按
- 滑动
- 条件判断（如果……才执行）
- 发网络请求
- 把多个组件打成一组再整体旋转
- 单个组件旋转

**变量**

- 全局变量：写进每一个页面，所有页面都能用。
- 页面变量：只写进选定的那一页。
- 文本内容写成 `$变量名` 时，预览和源码都会使用这个变量的值。
- 类型可以是文字、数字、是或否。

**预览**

预览用来看上面的动作会怎么走：切页、返回、提示、显示、隐藏、改文字、改变量。

预览不是蓝河官方模拟器，不能当成手表上的真实运行结果。

**代码和打包**

编辑器右侧有三块：

- 属性：改当前选中的东西。
- 代码：查看将要生成的文件，并下载源工程。
- 打包：向服务器申请官方编译。现在会得到「未执行」，见第 3 节。

## 7. 任务

任务页记录三类事情：

- 源工程：生成是否成功，以及文件指纹（SHA-256）。
- 官方打包：现在只会是未执行。
- 下载：是否已经扣过导出额度。

成功的源工程可以在这里再次下载。

## 8. 商城和投稿

**商城**

- 展示组件名称、编号、版本、作者、简介和获取方式。
- 编号从 MB001 这样的形式往下排，由后台填写。
- 获取方式分四种：免费、会员、指定卡密、付费。
- 「安装」只是把这个组件记到用户账号上，方便核对权限。
- 不会把一个来历不明的组件直接塞进画布。画布里能摆的，仍然只是第 6 节那张表。

**投稿**

- 用户可以申请成为开发者。
- 通过之后可以提交组件，等待审核。
- 管理员通过后才会出现在商城。拒绝要有结果，用户能看到审核状态。

## 9. 权益页

用户在这里看到：

- 邮箱、是不是会员、会员到期日
- 三种额度的余额，以及正在预留、还没最终确认的数量
- 购买次数、卡密、会员这三条路分别是什么意思
- 兑换卡密
- 可购买的套餐，以及提交订单
- 历史订单：待确认、已开通、已取消
- 额度流水：哪一次加了、扣了、退回了
- 当前版本记录。如果没有安装包地址，页面会写明还没有 Android 包

## 10. 后台能配置什么

后台不需要改代码就能处理日常运营。入口：`/admin`。

| 分页 | 用来做什么 |
|---|---|
| 总览 | 看用户、工程、额度的概况 |
| 用户 | 搜索用户，手动发会员，调整额度 |
| 组件 | 上架或修改组件，设置免费 / 会员 / 卡密 / 付费，填写编号 |
| 投稿 | 通过或拒绝开发者提交的组件 |
| 套餐 | 新建和修改套餐：名称、价格、天数、三种额度、同时任务数、工程上限 |
| 卡密 | 生成兑换码。明文只在生成时显示一次，之后后台看不到原文 |
| 订单 | 确认或取消。确认后才发放套餐权益 |
| 任务 | 查看用户的生成和打包记录 |
| 版本 | 填写版本名、版本号、是否强制更新、更新说明、安装包地址和校验值。没有真实安装包就不要填地址 |
| 开关 | 关闭或打开官方打包入口等运行开关 |
| 公告 | 发一条公告，显示在页面顶部 |
| 审计 | 查看管理员做过的操作 |

套餐价格、天数、送多少额度，都不要写死在宣传稿里。以后以后台当时配置的为准。

## 11. 手机、网页、电脑的关系

现在用户打开的是网页。

产品约定是：网页、Android、桌面都只是客户端。账号、工程、额度、商城、订单和生成记录都在服务器。以后做手机客户端或桌面客户端，不需要再做一套会员和额度。

所以策划可以按「一个账号，多端编辑同一个工程」来写，但不能把「已经有可安装的 App」写进上线说明。

页面底部可以分别下载：

- 服务器端源码
- 客户端源码
- 开发文档

这三份是交给研发的，不是交给手表用户的安装包。

## 12. 对外不要承诺的

下面这些现在都没有，评审和宣传不要写成已具备：

- 可安装的 Android APK
- 桌面客户端安装包
- 蓝河官方编译，以及由此产生的手表安装包
- 在线支付、自动到账
- 额度每天或每月自动恢复
- 长按、滑动、条件判断、网络请求
- 组件成组、旋转
- 把商城里任意一个新组件拖进画布就能用
- 预览结果等于手表真机效果

## 13. 建议策划保持的口径

一句话：

> 注册就能免费设计和保存手表界面。导出源码需要额度。官方打包尚未开放，不会扣次数，也不会发给用户一个假的安装包。会员、次数和组件权限分开卖。

需要对外稿时，把「源工程」和「安装包」写成两个词，不要互相代替。
