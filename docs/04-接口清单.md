# 客户端接口

普通客户端可以调用：

- `me` 当前用户、额度、会员、组件权限、允许的客户端
- `listProjects` / `syncProject` / `deleteProject` 云端工程
- `getProjectDoc` / `saveProjectDoc` / `listRevisions` / `validateProject` / `previewImport` / `importBundle` 统一协议 v2（见 docs/10-统一工程协议.md）
- `generate` 生成源工程
- `listJobs` / `downloadJob` 任务。
- `requestBuild` / `listBuilds` / `getBuild` / `cancelBuild` / `downloadBuild`：RPK 构建任务（预扣→确认/退回积分，详见 `docs/12-构建引擎.md`）。没有在线 Worker 时记为“不可用”，不扣分，不会假装编译成功
- `market` / `install` 组件商城
- `redeem` 卡密
- `listOrders` / `createOrder` 订单。支付第一阶段由后台确认
- `developerApply` / `mySubmissions` / `submitComponent` 投稿
- `ledger` 额度流水

后台另有用户、组件、投稿、套餐、卡密、订单、任务、开关、公告、审计。这些不进客户端共用名单。

额度扣减在服务器完成，顺序是预扣、成功确认、失败释放。客户端不能自己改余额。
