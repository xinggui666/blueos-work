# 多端是不是可以共用

可以，而且应该共用。

网页、Android、桌面端都是客户端。它们只负责登录、编辑和展示。账号、工程、额度、商城、生成和构建记录都在服务器。

三个客户端使用同一个地址和同一组动作名：

- 客户端标识：`web`、`android`、`desktop`
- 请求形态：`{ client, action, payload }`
- 动作名单见 `src/lib/contract/surface.ts` 的 `SHARED_ACTIONS`
- 管理后台动作以 `admin` 开头，只给有权限的账号，不开放给普通客户端

现在网页客户端发出的标识是 `web`。Android 或桌面端接上时，换标识即可，不用再写一套保存和生成逻辑。

服务端入口在 `src/lib/platform/functions.ts`，业务在 `src/lib/platform/logic.server.ts`。
