# 数据与生成

一个工程包含：

- 基本信息：名称、应用名、包名、圆表或方表
- 多个页面，其中一个是启动页
- 页面上的组件，绝对定位
- 点击动作：打开页面、返回、提示、显示、隐藏、改文字、改变量
- 导航：无、底部、顶部、侧边
- 变量
- 修订记录

画布、预览和导出的 DSL 使用同一份工程。无效 DSL 不会覆盖当前工程。

预览会真的执行点击动作，但屏幕上会写明「模拟预览，不是真机」。

导出的源工程按蓝河文档组织：

- `src/app.ux`
- `src/manifest.json`
- `src/pages/<页面名>/index.ux`

跳转使用文档中的 `router.push` / `router.back`（`@blueos.app.appmanager.router`）。提示使用 `prompt.showToast`，并声明 `blueos.window.prompt`。显示隐藏使用通用属性 `show`。文档里没有已核对的官方导航栏组件，所以导航会生成成按钮。

设计宽度仍是 466。这是当前蓝河手表画布，不是手机全屏应用画布。
