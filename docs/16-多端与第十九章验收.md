## 第十九章逐项解释

### 19.1 服务端

注册登录、真实 session 到期/失效、RBAC、工程 CRUD/并发冲突、组件权限/会员过期/组件 grant 过期、卡密并发、订单确认/退款、积分并发/预扣退回、构建任务幂等、文件 owner 权限、后台权限均有自动化证据。密码哈希、SQL 参数化、审计、限额等由实现与对应单测/集成用例支持；这不是专业渗透测试认证。

### 19.2 编辑器

自动化覆盖组件新增、层级/属性、页面文档、撤销/重做、保存、导入/导出与迁移；共享 store/model 测试覆盖部分排列/逻辑变更。**鼠标/触屏拖动缩放的完整人工矩阵、全部锁定/隐藏/多页面边界操作、系统文件选择器和容量满场景未全量人工验收**，不因 UI 复用就标为全部通过。

### 19.3 逻辑

浏览器用真实解释器验证点击/变量/条件和动作、函数参数/默认值/返回、循环/递归保护、计时器/时间格式/绑定及错误定位等单元/界面路径。长按/滑动在解释器有表达能力，**目标设备支持与手表事件行为待真实设备**。

### 19.4 Android

134 单测和 17 UI 测试、4 跨 UI 测试与 JVM 5 测试不等于 APK 运行验收。最终 Release APK 构建/正式签名已验证；早期构建模拟器 install Success，系统 TCG 运行不稳定，最终 APK 的安装/启动/登录/SAF/更新安装仍未验证。细节和真实系统 ANR 截图见 docs/15。

### 19.5 BlueOS 真机（全部待验收）

- [ ] 目标手表 RPK 安装与卸载。
- [ ] 页面、全部组件、圆表/方表适配。
- [ ] 点击、长按/滑动、页面生命周期与跳转/返回。
- [ ] 时间绑定、变量变化、定时器与恢复省电状态。
- [ ] 离开云平台/断网后本地独立运行。
